The Problem

Hospitals are running on
paper and guesswork.

📋

Paper Slips

Queue management via handwritten tokens. Lost slips mean lost patients.

📢

Manual Calling

Staff shout names across crowded waiting rooms. Missed calls, frustrated patients.

🚫

Zero Visibility

Patients have no idea when they'll be seen. Doctors can't see the queue state.

🔓

Unprotected Records

Medical data in spreadsheets or unencrypted systems. A compliance nightmare.

MediQueue fixes all of this
Core Features

Everything a modern hospital needs.

Doctors

Live Patient Queue Dashboard

Doctors see their full queue in real-time via Socket.io. Patient arrival, status, and priority — all in one glance. Queue updates propagate in under 200ms.

Real-Time Position Tracking

Security

AES-256 Encrypted Vault

Medical records encrypted at rest. Role-based access ensures only authorised staff can view sensitive data.

🔐
Admins

Central Operations Hub

Manage staff accounts, appointments, audit logs, and system health from a single admin dashboard.

⚙️
Auth

JWT + RBAC — Four Distinct Roles

Patient, Doctor, Admin, and Super Admin — each with scoped permissions enforced at middleware level. Token refresh, session management, and audit trails built-in.
